# Machine Learning Projects

This repository contains two Python machine learning implementations:

## Files

### 1. num.py
Implementation of 20 major NumPy functions from scratch using Python loops and recursion:
- Array operations: len, shape, size
- Statistical functions: sum, max, min, mean, std, var
- Array manipulation: sort, unique, reshape, flatten, concatenate, transpose
- Utility functions: product, count_nonzero, argmax, argmin
- Linear algebra: dot product

### 2. SLR.py
Simple Linear Regression implementation from scratch:
- Custom SLR class with fit and predict methods
- Uses least squares method for parameter estimation
- Includes visualization of predicted vs actual test values
- Uses sklearn for train-test split and r2_score evaluation

## Usage

```python
# For num.py
python num.py

# For SLR.py
python SLR.py
```

- scikit-learn
